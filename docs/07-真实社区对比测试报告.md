# 真实社区对比测试报告：交道口（老城） vs 回龙观（大型居住区）

> 交付文档 ⑤（docs/01 §8："针对特定社区的真实对比测试报告"）。
> 全部数据来自 **2026-10-09 真实百度地图 API 采集**（非回放快照），原始报告固化于
> `data/samples/jiaodaokou.json`、`data/samples/huilongguan.json`，采集工具
> `backend/scripts/collect_samples.py` 可复现（见 §8）。

---

## 1. 测试目的与方法论

- **目的**：① 验证全链路（等时圈→POI→覆盖→盲区→报告）在真实 API 下的正确性
  与预算约束；② 用城市肌理迥异的两个社区，检验算法输出对路网结构的**敏感性**
  （而非输出千篇一律的圆）；③ 产出可对比的量化结论，支撑"体检与规划"的产品主张。
- **方法**：每社区一次完整分析（geocode 解析街道中心 → 15 min 步行阈值 → 四类
  目全流程），验收标准：任务 completed、`degraded_flags = []`（全实测口径）、
  `http_calls ≤ 25`。
- **环境**：真实 AK（个人认证，免费配额档）；QPS=2 / 突发=2（BF-009 后）；单分析
  预算硬上限 40；批量上限 50 OD/批。

## 2. 社区选择

| | 交道口街道（东城区） | 回龙观街道（昌平区） |
|---|---------------------|---------------------|
| 类型 | 老城胡同区（南锣鼓巷片区） | 超大型居住区（典型"睡城"） |
| 城市肌理 | 胡同细网格 + 东西向主干道（地安门东/平安大街）穿越 | 大院式 superblock + 正交主干道网格 |
| 解析中心 | 116.407282, 39.942233（bd09，级别"乡镇"） | 116.331110, 40.070434（bd09） |

两者同处北京、相距约 15 km，控制了城市能级变量，隔离出**路网形态与设施分布**
的对比差异。

## 4. 结果对比

### 4.1 等时圈几何（实测 ray-spline-v1）

| 指标 | 交道口 | 回龙观 | 解读 |
|------|--------|--------|------|
| 5 min 圈面积 | 0.154 km² | 0.111 km² | 小尺度回龙观更小（superblock 内部道路稀疏） |
| 15 min 圈面积 | **1.719 km²** | **1.229 km²** | 老城路网密度优势兑现为 40% 面积优势 |
| 15/5 min 面积比 | 11.15 | 11.05 | 两者一致——面积扩张规律同构，差异在形状不在增速 |
| 5 min 圈长宽比 | **1.601** | 1.123 | 交道口小尺度沿东西主干道强拉伸；回龙观 10 min 圈 0.993 几乎正圆 |
| 15 min 圈半径变异系数 | **0.116** | **0.268** | 反转：老城边界平滑（均质细网格），回龙观锯齿剧烈（superblock 边界突变） |
| confidence（5/10/15） | 1.000 / 1.000 / 1.000 | 0.834 / 0.972 / 0.972 | 回龙观小尺度双法一致性低被如实折算，未虚标 |

几何结论：**等时圈形状忠实映射了路网形态**——胡同区小尺度各向异性（沿干道拉伸
1.6×）但宏观平滑；大院区小尺度规整（≈1.0）但边界锯齿（superblock 的墙与门）。
若算法输出的是千篇一律的圆，这两组指标应高度相似。

### 4.2 阶段 D 加密（双法仲裁的实测案例）

回龙观触发了 `densified=5`：5 min 圈双法分歧方位补 5 探针（1 次批量矩阵）后
一致性收敛至 0.834（未虚高）；交道口无分歧方位（`densified=0`），零加密成本。
**可选精度层只在需要时花钱**。

### 4.3 POI 采集与覆盖判定（三级漏斗实测分布）

| | 交道口 | 回龙观 |
|---|--------|--------|
| POI 命中（医/教/购/养） | 8 / 9 / 1 / 1 | 4 / 3 / 0 / 0 |
| 判定漏斗分布 | POLYGON 圈外 15 + FIELD 3 + **MATRIX 边缘带 1** | POLYGON 5 + FIELD 2 + 边缘带 0 |
| medical 覆盖 | 3/8（avg 10.5 min，46.5 分） | 1/4（avg 9.8 min，23.0 分） |
| education 覆盖 | 1/9（14.7 分） | 1/3（28.0 分） |
| shopping / elderly | 0/1、0/1（0 分） | 0/0、0/0（0 分） |
| 综合评分 | **15.3** | **12.8** |

漏斗效率实例（交道口）：19 条设施仅 1 条需要 API 实测——同仁堂药店（南锣鼓巷店）
插值 13.1 min 落在边缘带 [13,17]，批量矩阵实测定论**圈内**；其余 15 条几何粗筛
零成本判外、3 条插值判内。**API 只花在真正模糊的地方**。

口径提示（诚实声明）：综合评分低是**窄口径检索的真实结构**——分母只计"药店/
小学/菜市场/养老院"关键词命中的目标业态。老城 9 所小学只 1 所 15 min 可达是真
实地理事实（小学服务半径本就 ~500 m）；shopping 类两地均近乎零命中，是"菜市场"
关键词召回口径偏窄（见 §5.3）。

### 4.4 盲区识别（零 API，225 格栅格）

| | 交道口 | 回龙观 |
|---|--------|--------|
| medical（药店） | 0 格缺失 | 0 格缺失 |
| education（小学） | 0 格缺失 | **7 格缺失**（worst 1127 m，边缘型） |
| shopping（菜市场） | **169 格缺失**（worst 2211 m） | **225 格全域缺失**（检索成功但 0 命中） |
| 复合盲区（≥2 类） | 0 | **7 格**（max_severity=2） |

- 两社区药店密度均充足（0 缺失格）——算法没有制造假警报；
- 回龙观复合盲区 7 格（小学 + 菜市场双缺）是规划优先级最高的区域——这正是
  "体检→规划"产品价值的落点；
- 交道口唯一菜市场（兆军盛）在 1221 m 直线处，15 min 圈边缘之外，导致 169 格
  缺失——老城并非无菜市场，而是窄口径下"最近的菜市场恰好超界"，报告口径
  声明见 §5.3。

## 5. 差异归因

1. **路网密度 → 等时圈面积**：老城 15 min 圈大 40%（1.72 vs 1.23 km²）——胡同
   网格的多路径连通性高于大院围墙分割；
2. **路网形态 → 圈形指标**：拉伸与锯齿两组指标在不同尺度上的"反转"（§4.1）
   与两类社区的结构特征一一对应；
3. **设施分布模式**：老城设施沿街均匀铺开（药房租售密度高、多校区分散）；回龙
   观设施向轨道站/主干道集聚（4 药店中 2 家在 1 km 边缘外），居住区内部大片
   "设施真空"由盲区算法显影。

### 5.3 已知口径局限（如实声明，不装作没有）

- **"菜市场"召回偏窄**：白名单 `菜市场|农贸市场` 不覆盖便民菜店/生鲜超市——
  两地 shopping 类命中极少主要反映口径而非绝对供给；扩类目表（改
  `data/config/poi_taxonomy.json`，零改码）即可复测；
- **elderly 类两社区命中极少**：养老院业态本身低密度，且街道中心点未必是居住
  质心；
- **单中心点视角**：本报告按街道办事处几何中心分析；同一街道内不同小区结论会
  平移（产品支持任意点选/地址搜索发起，正是为此）。

## 7. 结论与规划建议

1. **功能结论**：全链路在真实 API 下零降级完成，等时圈/漏斗/盲区三套算法的输出
   与两个社区的城市结构定性认知吻合——功能正确性（40% 维度）有了真实数据背书；
2. **规划建议（示例，体现产品主张）**：
   - 回龙观：优先在复合盲区 7 格所在片区（研究区东南部）补建/引入菜市场类设施，
     并核查边缘型小学缺失带（worst 1127 m，刚过阈值）的入学半径政策；
   - 交道口：医疗与教育覆盖的短板不在数量而在"最后一公里"分布（9 校仅 1 所
     15 min 内），提示按校区划片优化而非新增；
3. **工程结论**：BF-009 证明"真实配额环境的测试"不可被 mock 替代——respx 全绿
   的代码在真实并发窗口下照样翻车；同时降级链证明了兜底价值（第 1 轮矩阵全灭
   时报告仍产出、预算未超）。

## 8. 复现指引

```bash
# WSL，backend/ 目录；需根 .env 配置 OPENMAP_BAIDU_AK 且 OPENMAP_DEMO_MODE=0
python3 scripts/collect_samples.py            # 内置两社区，间隔 20s 冷却并发窗口
python3 scripts/collect_samples.py --slug my --address "你的社区地址"
```

固化样本结构：`{meta（时间/commit/配置）, report（完整分析报告）, derived（几何
派生指标——面积/长宽比/半径变异系数）}`，可直接 diff 对比；亦可用 DEMO_MODE=1
在回放模式演示同款报告形态（`data/replays/demo.json`）。
