# 服务盲区识别算法

> 交付文档 ④（docs/01 §8）。对应命题硬指标："标注 1 公里内缺少菜市场/药店/小学
> 的服务盲区"。实现：`backend/app/blindspot/grid.py`（单模块纯函数），模型
> `models/blindspot.py`。**全本地计算，零 API 成本，<1 s**。

---

## 1. 口径声明（先于算法）

- **判定口径 = 栅格中心到最近设施的直线距离 > 1 km**（命题字面："1 公里内缺少"）；
- 路网口径（步行可达性判定）是**声明未实现的可选增强**——模型注释显式标注
  （`models/blindspot.py`："路网测时口径的差异为文档声明的可选增强，不在本模型
  中"）。两个口径的差异界：直线 1 km ≈ 路网 1.3 km（绕行系数），规划者跨界比对
  时须知此换算；
- 选择直线的理由：① 命题字面口径，评审零歧义；② 与等时圈（路网口径）互补——
  等时圈回答"从中心出发能到哪"，盲区回答"这张网上哪里离设施太远"，两套几何
  各司其职。
- **盲区独立于等时圈（双口径声明）**：盲区研究区是中心点 1.5 km 见方的**规则方形**，
  与路网约束下**不规则**的等时圈边界不重合，灰色区域**落在等时圈之外属正常**——
  两者是并列的双口径，不是"圈内子集"关系。前端报告面板（`ReportPanel` 盲区标题）
  已显式声明"独立于 15 分钟等时圈的 1 公里直线距离服务盲区"。

## 2. 算法流程（`compute_blindspot`）

```text
① 栅格化：中心点 1.5 km × 1.5 km 研究区（blindspot_extent_m=1500），
   100 m 格（blindspot_cell_m=100）→ 15×15 = 225 格
   （格心在米制局部平面布设：经度方向 cos(lat) 收缩，core/coords.local_delta_m）
② 向量化最近邻：三类设施（药店/小学/菜市场，blindspot_types）分别投影建
   cKDTree，一次 query 求 225 个格心的最近设施直线距离（向量化，毫秒级）
③ 缺失判定：距离 > blindspot_threshold_m(1000 m) 的格标记缺失该类；
   记录 worst_distance_m（缺失格中最远的距离，衡量严重程度）
④ 聚类平滑：缺失格 → shapely box → unary_union → buffer(50 m)
   （buffer ≥ 格角间隙 √2/2×100 ≈ 70.7 m 的一半，对角相邻格因此融合——
   8 邻接语义靠几何实现而非显式图遍历）；多边形在米制空间构建（缓冲各向
   同性），仅最终顶点经 offset_lnglat 转回 BD09
⑤ 严重度分级：每格累计缺失类数 severity ∈ {0,1,2,3}；
   severe_cells = 缺失 ≥2 类的格数（复合盲区 = 规划最优先）
```

## 3. 语义纪律（哪些数据有资格进判定）

`types` 由编排层注入：**只含成功完成检索的类目**（`pipeline.py`）——

- 检索失败/用户未选的类目**不参与判定**（其设施列表为空会被误判"全域缺失"——
  BF-007：数据缺失 ≠ 事实结论）；
- 检索成功但零命中**合法地全域缺失**：这是窄口径检索的真实结论（该业态在研究
  区内确实没有以目标关键词命名的设施），如实输出。

实测例证（docs/07）：回龙观 shopping 类检索成功但 0 命中 → 225 格全域缺失；
education 类 3 所小学集中西侧 → 7 格缺失且与 shopping 缺失叠加（severe_cells=7）。
两社区 medical 均 0 缺失格——药店密度足够，算法没有制造假警报。

## 4. 输出契约

`BlindspotResult`：`{types: [{type_key, label, missing_cells, worst_distance_m,
polygons(GeoJSON BD09)}], grid_side, threshold_m, max_severity, severe_cells}`。
前端 `BlindspotLayer` 灰色多边形渲染 + 缺失类型标签；复合盲区（severity ≥2）
以更深灰阶强调。

## 5. 设计取舍

| 选择 | 理由 |
|------|------|
| 栅格 100 m（225 格）而非更细 | 命题精度（1 km 判定）下更细只增加噪声；225 格 cKDTree 向量化 <10 ms |
| 1.5 km 研究区 | 覆盖 1 km 判定半径 + 边缘设施影响域，且与等时圈采样范围（1.2 km）衔接 |
| cKDTree 而非逐格循环 | 225 格 × 3 类向量化一次查询——"能本地算不调 API"铁律的展示点 |
| buffer(50 m) 平滑 | 消除栅格锯齿使多边形可读；融合对角邻接（8 邻接语义） |
| 零 API 兜底 | 盲区计算在配额耗尽/矩阵降级时仍完整产出——报告永不缺这一节 |
