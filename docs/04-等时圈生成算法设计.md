# 等时圈生成算法设计（基于路网计算可达范围）

> 交付文档 ②（docs/01 §8）。回答命题的核心问题：**在不获取底层路网数据的前提
> 下，如何用地图开放 API 计算真实路网约束下的步行可达范围**。实现全部位于
> `backend/app/isochrone/`（纯函数域层，模块：sampler / field / fitter / grid /
> reconcile / engine），编排入口 `compute_isochrone`。

---

## 1. 问题定义与总纲

**约束**：命题禁止抓取底层路网（OSM 等），路网信息只能以"路径规划 API 返回的
耗时"形式获得（黑盒测时探针）。

**解法**：把连续的等时线求解离散化为**有限个 OD 对的测时问题**，再用几何方法
重建边界——"并行二分扇形采样 + 时间场双重表达"五阶段：

```text
A 扇形粗采样（建时间场骨架） → B 并行二分（临界点收敛）
→ C 双法拟合（样条主法 + 等值线第二法交叉校验） → D 加密与飞地补采（可选精度层）
→ E 逐级输出（5/10/15 min 多级圈 + confidence）
```

**预算视角**：64 探针粗采样 ≈ 2 批 + 二分 3 轮 × 1 批 + 加密 ≤ 1 批 ≈ **6 次矩阵
调用**封顶（对比逐探针单路规划的 100+ 次）；实测两社区各 4~5 批（docs/07）。

## 2. 阶段 A：扇形粗采样

- 以中心点为极点，`isochrone_directions = 16` 个方向（22.5° 间隔）；
- 每方向 `isochrone_rings_m = [300, 600, 900, 1200]` 四档距离探针（覆盖 15 min
  步行量级并留外推余量）→ 共 **64 个 OD 对**；
- 全部 OD 经 `route_matrix` 批量测量（分片 50/批，2 次调用）；探针点位在
  **米制局部平面**布设（`core/coords.py: local_delta_m`，经度方向按 cos(lat)
  收缩，与 haversine 同源的球体常数——BF-001 教训：椭球/球体常数混用会漂移）；
- 产出：64 个 `(方向θ, 距离 d, 实测耗时 t)` 三元组 → `TimeField` 散点时间场；
- **受阻方向**：某方向全环不可达（返回 null）→ 标记 blocked，后续该方向用相邻
  插值补齐并降低 confidence（河流/围墙/封闭区的圈形凹陷由此产生）。

## 3. 阶段 B：并行二分细化

- 每方向找耗时跨越目标 T 的相邻档 `(d_lo, d_hi)`（bracket）；
- 16 方向**同时**二分（`isochrone_refine_rounds = 3` 轮），每轮中点**攒批成 1 次
  矩阵调用**（16 OD/批，绝不逐方向单发）；
- 3 轮后区间收敛至约 75~150 m（1200−300 → 75 m 量级），对应时间分辨率 ≈ 1 min；
- blocked 方向不参与二分（不浪费预算测必然不可达的探针）。

## 4. 阶段 C：双法拟合与交叉校验（几何可信度的来源）

**主法——极坐标样条**（`fitter.py`，几何出口）：

- 每级别取各方向临界半径 `(θ_i, r_i)`，在米制平面转直角坐标后做 Catmull-Rom
  闭合样条 → 平滑多边形 → shapely `make_valid` 修复自交；
- blocked 方向由相邻方向角度插值补齐，该级别 confidence 按方向覆盖率打折。

**第二法——时间场等值线**（`grid.py`，只校验不出图）：

- 散点时间场 `griddata` 线性插值到 100 m 网格（`isochrone_grid_step_m`），范围
  半径 2400 m（`isochrone_grid_extent_m`），**含外推虚拟环**保证高级别等值线
  闭合（外推不超过最远样本 1.3×，防止无依据外推）；
- 自研 **marching squares** 提取 5/10/15 min 等值线（避免对 matplotlib 的运行时
  依赖；闭合环转 shapely Polygon）。

**双法一致性 → confidence**（`reconcile.grid_consistency`）：

- 逐方向取等值线在射线上的半径 `r_c` 与样条临界半径 `r_s`，
  `consistency = mean(1 − |r_c − r_s| / max(r_c, r_s))`；
- 折入公式：**`confidence = base × (1 − 0.5 × (1 − consistency))`**——完全一致
  不罚，完全背离对折（两个独立方法的几何主张相互印证，是"低采样密度下边界
  可信"的核心论据，也是 30% 工程优化维度"空间插值创新"的落点）。

## 5. 阶段 D：加密与飞地补采（可选精度层）

触发条件与探针布设（`reconcile.py`，全部合并为 **1 次批量矩阵调用**）：

| 触发 | 判据 | 探针 |
|------|------|------|
| 双法分歧 | 方向偏差 > `isochrone_verify_tolerance_m`（100 m） | 在**等值线主张的半径**上补 1 探针——一次实测即可仲裁两法谁可信 |
| 飞地疑似 | 相邻方向临界半径比 ≥ `isochrone_enclave_jump_ratio`（2×） | 扇区中点两侧各补 1 探针（天桥/桥梁连通的独立可达区） |

护栏：

- 单轮探针上限 `isochrone_densify_max_probes = 10`（恰一批矩阵）；
- **整层跳过原则**：剩余预算不足以覆盖整层时全部跳过——不做半截采样，避免
  "按失败时机选择实测对象"的选择偏差；
- 加密层失败（矩阵故障/契约违反）只记 `densify_unavailable` 日志、**不升级降级
  标记**——主几何仍是实测口径；
- 实测样本中回龙观触发 5 个加密探针并收敛（`densified=5`，docs/07 §4.3）。

## 6. 降级与预算交互（docs/02 §3.4 的等时圈特例）

- 矩阵失败 → **直接落第三级**直线 × 1.3 ÷ 1.35 m/s 估算（跳过逐条中间级：64
  探针逐条会爆预算），`confidence` 封顶 `fallback_confidence_cap = 0.3`，
  `method` 切换 `straight-estimate`，`degraded_reason` 声明
  `matrix:unavailable`；
- 预算耗尽（`budget:exhausted`）→ 同样落估算收尾，保证**任何情况下报告可产出**；
- 两级降级在前端有显式文案（"低置信度，几何仅供参考"）。

## 7. 误差控制

| 误差源 | 上界 | 控制手段 |
|--------|------|---------|
| 方向离散 | 相邻方向间边界形状未知（22.5° 扇区） | 16 方向 + 样条平滑；双法一致性监测 |
| 距离离散 | 二分区间 75~150 m ≈ 步行 1~2 min | 3 轮二分；边缘带设施另有覆盖漏斗实测兜底 |
| 插值外推 | 最远样本 1.3× 处截断 | 网格外推环上限；超环等值线退单法 |
| 单次测时噪声 | 路况波动（分钟级） | duration 为 API 综合口径；confidence 不装作比数据更准 |

**口径声明**：等时圈精度受方向采样密度约束——它是"16 条射线上的真值 + 插值
主张"，不是路网全量真值。这个诚实声明与 confidence 机制本身，就是误差控制的一
部分（评审可感知的严谨性）。

## 8. 实测表现（详见 docs/07）

| 指标 | 交道口（老城胡同） | 回龙观（大型居住区） |
|------|-------------------|---------------------|
| method | ray-spline-v1（实测） | ray-spline-v1（实测） |
| 探针数 / 矩阵批次 | 112 / 5 | 117 / 6（含加密 5 探针） |
| 15 min 圈面积 | 1.72 km² | 1.23 km² |
| 5 min 圈长宽比 | 1.60（小尺度沿东西主干道强拉伸） | 1.12（正交路网规整，10 min 圈 0.99） |
| 15 min 圈半径变异系数 | 0.116（老城均质细网格，边界平滑） | 0.268（superblock 边界突变） |
| confidence（5/10/15 min） | 1.000 / 1.000 / 1.000 | 0.834 / 0.972 / 0.972 |

两个城市肌理迥异的社区，等时圈形状量化指标呈现清晰分化——算法对路网结构的
敏感性（而非输出千篇一律的圆）是正确性的最好佐证。

## 9. 为什么不用替代方案（选型论证摘要）

- **OSM + Dijkstra**：命题红线（不得获取底层路网）；
- **纯缓冲区（直线半径圆）**：无视路网，河流/铁路/封闭区全部失真——本项目第
  三级降级的口径，仅作兜底并显式低置信度声明；
- **逐点路径规划**：调用次数爆炸（300+ 次/分析），配额与耗时都不可行；
- **本方案**：以 ~6 次批量调用获得"采样射线上的路网真值 + 双法互证的插值边界"，
  在配额、精度、可信度三者的约束区间内取最优。
