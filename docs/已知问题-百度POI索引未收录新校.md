# 已知问题：百度周边检索索引未收录新校，教育类目漏召回（含小学部）

- 记录日期：2026-10-11
- 状态：**待决策**（未修复；已做一项不解决本问题的缓解，见下）
- 影响模块：`app/poi/`（**召回层**，非清洗/过滤层）
- 对应报障：杭州市城北万象城 15 分钟生活圈「缺小学」——官方口径确认为「良运实验学校」
  （九年一贯制、含小学部）就在附近，但报告判其缺失。

## 现象

用户以「杭州市城北万象城」为中心体检，报告盲区模块报「缺小学」。附近确有一所含小学部的
九年一贯制学校「良运实验学校」（好运街，官方新闻 https://hznews.hangzhou.com.cn/kejiao/
content/2025-08/26/content_9068765.htm 确认），却未进入教育类目检索结果。

## 根因分析（真实 API 实测，2026-10-11）

中心点「城北万象城」geocode → `120.119401, 30.358413`。半径 1300m 逐 query 实测：

| query | 结果 |
|-------|------|
| `学校` | 仅 沈括小学(通运校区) 1000m、良渚沈括小学 1292m（+1 门禁） |
| `小学` | 沈括小学 2 个校区 |
| `九年一贯制` | **0 条** |
| `九年一贯制学校` | **0 条** |
| `良运实验学校`（全名） | **0 条** |
| `好运` | 19 条（无学校） |

而 geocode「良运实验学校」→ `level=NoClass, precise=0, confidence=50`（模糊、未分类）。

**结论：该学校不在百度「周边检索」(`place/v3/around`) 的 POI 索引中**，仅 geocode 索引留了
一个未分类模糊点。因此：

- 任何 query 词（含「九年一贯制」）都召不回索引里没有的 POI；
- 这是 **数据源缺口**，不是检索/过滤逻辑 bug，代码层无法自愈。

与 BF-010（`docs/bugfix/2026-10-09-poi-primary-school-recall.md`）同属「召回层缺失」家族，
但更彻底：BF-010 的实验小学至少还有「西门」门禁 POI 可捞，良运这家连门禁 POI 都没有。

## 已做的缓解（不解决本问题，仅通用加固）

2026-10-11（未提交）：教育类目加「九年一贯制」第三检索词
（`data/config/poi_taxonomy.json` + `poi/service.py` DEFAULT_TAXONOMY），回放池与预算断言同步。
作用：**对"已被索引但仅 tag 含九年一贯制"的学校**多一条召回通道；对良运这类「未被索引」
的学校**无效**（实测 `九年一贯制` query 在万象城周边返回 0 条）。

## 为什么「网上检索判定」也救不了这个 case

设想功能「召回一个学校、判不出有没有小学部 → 拿校名去网上检索」的触发前提是**该学校已被
召回**。而良运是「压根没被召回」，连校名都拿不到，无从检索。因此该功能只覆盖一个更罕见的
残差场景（已召回但 tag 无「小学/中学/九年一贯制」子类），且属于新增出站 HTTP 源（违反
CLAUDE.md 铁律 #3，需先扩 provider 协议）+ 判定器（关键词匹配网页片段脆弱，可靠需接 LLM）。

## 待决方向（三选一，暂未定）

1. **维持现状**：接受新校在百度补录前（通常数月~1~2 年）对系统不可见，仅保留已加的检索词加固。
2. **官方名录离线融合（第二数据源）**：接入教育局公开的学校名录，做一次离线融合，作为
   POI 召回后的补充（覆盖含小学部的九年一贯制/实验学校）。属数据接入项目，需估算成本与维护方式。
3. **网上检索判定（最小验证）**：仅对「已召回但 tag 无子类」的学校，用固定检索模板跑一次，
   先看命中率再决定是否常驻。

## 复发信号

- 教育类目在**新开发片区**（新校密集）召回偏少；
- 用户报障「XX 学校明明在附近，报告却判缺小学」，且该校见诸近 1~2 年新闻（大概率尚未被
  百度周边检索收录）。
- 复现手法：`geocode` 目标校名若返回 `precise=0 / level=NoClass`，基本可判定未被索引收录。
