# BF-001 等时圈回放大面积误判不可达（地球模型混用 + 方位角度空间畸变）

- 日期：2026-09-30 　提交：a377f8f 　影响模块：`isochrone/sampler` `core/coords` `mapapi/replay`

## 现象

M2 等时圈域层首次联调（回放模式，中关村快照）：15 分钟圈 16 个方向中 **14 个方向被误判 BLOCKED**，
半径齐齐退到 900m；二分细化仅产生 4 个区间（预期 ~13）。结果多边形呈"切角矩形"而非真实形态。

## 根因分析

两个独立缺陷叠加，定位过程：先打印每方向 `level_radius` 状态 → 发现"不可达"集中在最外档（1200m）探针 →
复查回放 Provider 判达逻辑 `straight = haversine(...) > cap_m` →

1. **地球模型混用（主因）**：`sampler` 布设探针用椭球近似常数（110540 m/deg 纬、111320 m/deg 经），
   而回放判达用 `haversine`（球体 R=6371008.8 → 111194.9 m/deg）。1200m 档探针的真实球面距离 ≈ 1207m，
   恰好越过快照 `cap_m=1200` 的刀锋边界 → 整方向判死。0.6% 的系统性距离膨胀在 cap 边界被放大成 0/1 判定翻转。
2. **方位角在度空间计算（次因）**：回放 `_bearing_rad` 直接 `atan2(dlat, dlng)`（度），而采样极坐标在米空间。
   经度轴被 cos(纬度)≈0.77 压缩 → 135° 射线被认成 142.4°，方向插值把河流方向的 detour 1.9 混入 135° 方向
   （实测该方向 15min 半径 809.5m，理论 934.6m）。

## 修复方案

- `core/coords.py`：新增单一地球常数源 `EARTH_RADIUS_M = 6371008.8` / `M_PER_DEG = πR/180`，`haversine_m` 引用之；
  `sampler` 的两个投影常数改从 `M_PER_DEG` 派生——**布设与度量永远同一模型**
- `mapapi/replay/client.py`：`_bearing_rad` 改米空间 `atan2(dy, dy)`（度差 × M_PER_DEG/cos）
- 快照 `cap_m`：正常方向 1200 → 1500（cap 不应贴着采样档边界，浮点噪声即翻车）；河流方向 450、过渡 1100 保留

## 验证结果

修复后 15min 各方向半径与理论值（r = 900·speed/detour）逐一吻合：

```
0.0°=1157.1(ok)  90.0°=972.0(ok)  135.0°=934.6(ok)  157.5°=300(blocked, 河流)
180.0°=900(blocked, cap 1100)  247.5°=1215.0(extrapolated, detour 1.00)
probes=103（64 粗采样 + 13×3 二分） batches=5  15min conf=0.908
```

回归测试：`tests/unit/test_isochrone.py::test_probe_radius_matches_haversine`
（6 方位 × 3 半径参数化，|haversine − 布设半径| ≤ 2m）。

## 影响范围与注意事项

- 仅影响回放模式与几何布设；真实 API 测时不受地球模型影响（距离由百度侧计算）
- **复发信号**：回放模式下多方向同时 BLOCKED、或某方向半径明显偏离其 detour 理论值
- 教训：任何"米 ↔ 度"换算必须与度量函数同源；0.x% 的常数偏差在阈值判定处会变成 100% 的布尔翻转
